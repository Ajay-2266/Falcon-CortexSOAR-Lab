# EDR Investigation & SOAR Automation using CrowdStrike Falcon & Cortex SOAR

## Overview

This project demonstrates an Endpoint Detection and Response (EDR) investigation workflow integrated with Security Orchestration, Automation, and Response (SOAR) automation. The objective is to investigate suspicious endpoint activity, enrich Indicators of Compromise (IOCs) using Threat Intelligence sources, and automate incident handling through Cortex SOAR playbooks.

The project simulates a Security Operations Center (SOC) environment where alerts generated by CrowdStrike Falcon are analyzed, enriched, and processed through automated workflows to improve incident response efficiency.

---

## Objectives

* Investigate endpoint security alerts using CrowdStrike Falcon.
* Analyze process execution and endpoint telemetry.
* Identify and validate Indicators of Compromise (IOCs).
* Enrich IOCs using external Threat Intelligence sources.
* Automate alert triage and incident creation using Cortex SOAR.
* Map security events to the MITRE ATT&CK framework.
* Generate incident reports and response recommendations.
